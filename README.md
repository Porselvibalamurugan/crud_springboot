# 📝 CRUD Application

A simple **CRUD (Create, Read, Update, Delete) Application** built using **Spring Boot** .

## ✨ Features

- ➕ Create new records  
- 📖 Read and retrieve data  
- ✏️ Update existing records  
- ❌ Delete records  


## 🛠️ Technologies Used

- **Spring Boot**
- **Java**
- **Spring Data JPA**
- **Maven**


## 🎯 Purpose

This project was developed to **learn and practice CRUD operations using Spring Boot**, including API development, database connectivity, and backend architecture.
